# Reelva

Reelva 是一款 Windows / Android 影视库播放器：扫描你自己的视频文件，整理成带海报的影视库，记住观看进度。它不提供任何视频资源，也不会上传你的视频。

## 功能特点

- **媒体源**：直接添加电脑文件夹，或通过 WebDAV / SMB 播放 NAS、网盘上的视频；扫描保留原视频文件，刮削信息与图片可随媒体目录保存为通用 NFO、海报和背景图。
- **影视库**：按电影 / 电视剧整理海报墙，一部作品的多版本、剧集的季集结构清晰可查。
- **可选 TMDB 识别**：填入自己的 TMDB API 密钥后，点击影视库刷新按钮匹配海报与简介；也支持手动改名、改简介纠错。
- **进度记忆**：自动保存观看进度，首页「继续观看」一键续播，「最近添加」方便找新片。
- **内置播放器**：倍速、音量、全屏，可选择内嵌字幕与音轨，支持键盘快捷键。
- **跨设备同步**（可选）：多台设备通过同一个 WebDAV 目录手动同步进度；同步媒体源、凭据、播放器设置、快捷键和影视库索引，可选独立密码加密；新设备恢复后无需重新扫描，不上传视频。

## 下载安装

当前预发布版本为 [v0.1.0-beta1](https://github.com/miludeshiji/Reelva/releases/tag/v0.1.0-beta1)。**beta版可能存在大量bug，无必要请勿下载**。请在该版本页面按平台选择下载文件：

| 文件 | 适合 | 使用方式 |
| --- | --- | --- |
| `Reelva-<版本>-windows-x64.zip` | Windows 10/11（64 位） | 解压后直接运行其中的 `reelva.exe` |
| `Reelva-<版本>-windows-x64-installer.exe` | Windows 10/11（64 位） | 标准安装程序，可生成开始菜单 / 桌面快捷方式 |
| `Reelva-<版本>-android-arm64-v8a.apk` | Android 7.0+（64 位 ARM） | 主流手机选这个 |
| `Reelva-<版本>-android-armeabi-v7a.apk` | Android 7.0+（32 位 ARM） | 老设备备用 |
| `Reelva-<版本>-android-x86_64.apk` | Android 7.0+（x86_64） | 模拟器 / x86 设备选这个 |
| `Source code (zip / tar.gz)` | 开发者 | 源代码，普通用户无需下载 |

安装 Android APK：打开 APK 文件，按系统提示允许该来源安装应用，完成安装即可。

## 首次使用

1. **添加媒体源**：进入「媒体源」→「添加媒体源」，选择电脑上的视频文件夹（或填写 WebDAV / SMB 地址），应用会自动扫描。也可先在首页点「打开播放器」直接播放单个视频文件。
2. **浏览影视库**：扫描完成后进入「影视库」，点击刷新按钮匹配已有索引中的作品，随后点击海报进入详情，选择文件版本或剧集开始播放。
3. **（可选）配置 TMDB**：在「设置 → TMDB 凭据配置」填入自己的 [TMDB API 密钥](https://www.themoviedb.org/settings/api)，在影视库点击刷新按钮即可匹配海报与简介；不配置也能正常浏览和播放。
4. **继续观看**：没看完的影片会出现在首页「继续观看」，点击即可续播。
5. **（可选）跨设备同步**：在「设置 → 跨设备同步」为每台设备填写同一个 WebDAV 目录并保存配置，再在各设备上分别点「立即同步」合并进度。跨设备关联依赖 TMDB 匹配身份，详见[用户指南](docs/user/guide.md)。

详细操作见[用户指南](docs/user/guide.md)。
