# Reelva 用户指南

Reelva 是一款 Windows / Android 影视库播放器，用来管理并播放**你自己的视频文件**。它不提供任何视频资源：扫描只建立索引，不会复制、移动或上传你的视频。

安装步骤见[根 README](../../README.md)。本文按功能介绍日常使用。

## 快速上手

1. 打开应用，进入「媒体源」→「添加媒体源」，选择本地目录、WebDAV、OpenList 或 SMB，再在配置页填写信息并添加。
2. 保存后即可返回并继续使用，在「媒体源」查看后台扫描与识别状态，处理完成后进入「影视库」浏览作品。
3. 点击作品进入详情，选择文件版本或剧集开始播放。
4. （可选）进入「设置 → TMDB 识别」配置页，填入 TMDB API 密钥，自动补全海报与简介。
5. 没看完的影片会出现在首页「继续观看」，点击即可续播。

只想临时播放一个视频？在首页点「打开播放器」，在播放页通过「选择本地视频」选择文件，或「输入网络链接」播放。这种方式不会创建影视库条目，也不会产生观看历史。

## 媒体源

「媒体源」页面管理视频来源，所有来源共用同一套扫描、文件名识别与播放流程。

### 添加来源

点击「添加媒体源」进入来源选择页，再点击对应的来源卡片进入配置页。显示名称可不填；视频扩展名、排除目录和部分连接设置位于「高级选项」。常见填法：

| 类型 | 地址示例 | 其他填写项 |
| --- | --- | --- |
| 本地目录 | 点击「选择目录并添加」，通过 Windows 系统目录选择器或 Android 文件授权（SAF）选择文件夹；取消选择会留在配置页 | — |
| WebDAV | `https://nas.example/dav/Movies/` | 用户名、密码按需填写 |
| OpenList | 实例地址 `https://files.example/base` 加独立根目录 `/Movies`，也可合并写成 `https://files.example/base#/Movies` | API 令牌、目录密码；可选 User-Agent / Referer |
| SMB | `smb://nas.example/Movies`（可带端口与子目录） | 账号、密码、域；支持匿名 |

注意事项：

- 根目录地址不要内嵌账号密码、查询参数或相对跳转段，凭据请填在对应输入框。
- 使用 HTTPS 的 WebDAV / OpenList 需服务端持有可信 TLS 证书。
- SMB 仅支持 SMB2/3（含 NTLM 认证），不支持 SMB1。
- OpenList 按官方目录接口适配，不保证所有网盘后端都兼容；只有显式填写的 User-Agent / Referer 会用于播放。

### 扫描与源管理

点击媒体源卡片可进入文件目录，点击文件夹逐级浏览。文件与文件夹右侧的复选框用于选择视频，勾选文件夹会包含下级目录中的视频；支持跨目录选择，父文件夹会显示部分选中状态。选中后，底部操作栏提供「自动匹配」和「手动匹配」，只处理此次勾选的文件。

- 媒体源保存后立即返回列表并开始首次扫描，源卡片上实时显示已访问目录数与发现视频数，可随时取消；扫描失败会保留媒体源配置，可检查连接或权限后重新扫描。
- 扫描完成后自动整理影片与剧集，并在配置了 TMDB 时补充海报与简介；媒体源页和影视库显示当前处理阶段、匹配进度及完成结果，切换页面不会中断处理。未配置 TMDB 时显示本地识别完成，不作为添加失败。
- 空闲时可对单个来源重新扫描；扫描失败或取消不会清空已建立的影视库。
- 卡片菜单支持重命名、同根目录重新授权（Android 授权过期时使用）与移除来源。
- 移除来源只是停用它：作品、手动修正和观看历史都会保留，保存的密码等凭据会被删除；之后可重新添加同一来源。

### 视频筛选

默认只索引 `mkv, mp4, avi, mov, m4v, ts, webm` 扩展名的文件，并跳过 `.cache`、`$RECYCLE.BIN`、`System Volume Information` 等目录，添加来源时均可修改。

### 凭据安全

密码、令牌和播放请求头保存在系统安全存储，数据库不保存明文；输入框不回显旧秘密，源卡片菜单可「修改凭据」。

## 影视库与播放

- 影视库按作品展示海报墙，一部作品只显示一张卡片，可向下翻页加载更多。
- 电影详情列出各个文件版本；剧集详情按季 / 集整理。选择文件即可播放。
- 来源离线或文件缺失时记录仍保留，会提示错误，可重试或换文件。

### 播放器

提供播放 / 暂停、进度拖动、倍速、音量、静音、全屏，以及字幕与音轨选择（自动、指定轨道或关闭）。点击音量按钮可展开音量滑块和静音选项，取消静音时恢复之前的音量。Windows 本地文件支持自动加载同目录中名称匹配的字幕与音频，可在播放器设置中关闭或改为严格同名；暂不支持手动选择外挂文件，也不支持网络媒体源和 Android 授权单文件的同目录自动加载。

点击视频后直接进入播放画面，返回、标题和播放控件悬浮在视频上方。播放时控件会自动隐藏，点击画面可显示或隐藏；移动鼠标也可唤出控件。音量面板展开期间控件保持可见，再次点击音量按钮、点击面板外部或按 Esc 可关闭。窄屏下，字幕、音轨和倍速收在「播放设置」中，音量仍通过底栏按钮调节。

Android 播放器读取视频实际显示宽高后，横屏视频自动横屏播放，竖屏视频保持竖屏；退出播放器后恢复系统方向设置。返回时保留进入播放器前的页面与浏览状态。

键盘快捷键：

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 后退 / 前进 10 秒 |
| ↑ / ↓ | 音量 ±5% |
| Esc | 退出全屏 |

### 播放器设置

进入「设置 → 播放器」调整以下选项，点击「保存设置」后，下次进入播放器生效。配置只保存在本机，不参与跨设备同步；「恢复默认值」会重置表单，仍需保存。

- **视频**：自动硬件解码、高质量缩放、去色带与抖动目标色深。Windows 默认开启高质量缩放和去色带；Android 默认关闭这两项以减少负载。色深默认自动，不强制假定屏幕支持 10 位输出。
- **缓存**：默认使用内存预读，不写入磁盘；Windows 前向缓存上限为 1024 MiB，Android 为 128 MiB，按需使用且不预先分配；另保留最多 64 MiB 的回退缓存。
- **音频**：倍速音调修正默认开启，最大音量默认 200%，可降至 100% 或 150%。100% 以上为软件放大，可能失真；同目录音频默认模糊匹配。
- **字幕**：默认优先中文、其次英文；可调整同目录加载规则、字体、字号、黑色描边、柔化、垂直边距、ASS 样式覆盖和随视频处理。字幕使用 libmpv/libass 渲染；Windows 默认微软雅黑，Android 附带 Noto Sans CJK SC 中文字体。普通文本字幕使用自定义字号和描边；覆盖 ASS 原有字体等样式时，需选择「使用自定义字幕样式」。

独立 mpv 的窗口、D3D11 后端、ICC 自动配置、显示同步插帧、SVP、截图与个人路径不直接套用到应用。具体适配说明见[播放器配置](../development/player_configuration.md)。

### 网络源播放

播放 WebDAV / OpenList 文件时按需读取，随机定位取决于服务器是否支持 HTTP Range 请求；仅支持整体下载的服务器只能顺序播放。播放 SMB 文件时同样按需读取，无需预先复制整部视频。地址过期或访问被拒时会自动重新解析并重试，仍失败时给出提示，可手动重试或换文件。

## TMDB 识别与纠错

TMDB 配置是**可选**的：没有密钥也能浏览、播放和保存进度，只是无法获取新的在线资料，已保存和已缓存的内容仍可用。

### 配置密钥

在 [TMDB 官网](https://www.themoviedb.org/settings/api)申请后，于「设置 → TMDB 识别」配置页填入 API Key 或 API Read Access Token（可直接粘贴带 `Bearer` 前缀的令牌）。凭据保存在系统安全存储，可随时移除。

### 自动与手动匹配

- 扫描完成或打开影视库后，应用结合具体作品目录的中文标题与文件内原名、罗马音检索 TMDB；缺少年份也会搜索，带年份无合适结果时会移除年份过滤重试，再核验详情、别名、类型和季集。目录的字母索引、评分及画质标签不参与标题匹配，剧场版与 TV 分开识别；候选不确定时保留本地条目和推荐结果。
- 整理结果中的「未自动匹配」是本轮尚未确认 TMDB 身份的本地条目数量，可能包含尚未归并的分集文件，不代表相同数量的独立作品。点击「查看待匹配条目」或影视库的「待匹配」筛选可查看当前列表，点击条目即可手动匹配，确认后会自动移出列表；同一剧集的多个文件也可在媒体源按文件夹批量匹配。
- 媒体源文件目录或作品详情页可打开统一的「手动匹配」页面：输入关键词与可选年份，一次搜索同时返回电影和剧集，无需切换作品类型。选择目标后预览文件对应关系，确认前不会修改匹配。
- 剧集优先读取文件名中的 `S02E03`、`1x05` 等季集号；单独的 `E03`、`EP03` 或纯数字集号可从所属 `S02`、`Season 02` 等文件夹补充季号。文件名为 `01`、`02` 等纯数字且没有季号时，默认填写第 1 季及对应集数；明确的文件或目录季号优先保留。其他缺失季号可批量补全，季集也可逐行修正或取消勾选。TMDB 确认季集存在后才应用；多集合集文件需取消勾选后单独处理。
- 支持字幕组常见的 `[01]`、`[13v2]`、`- 01` 编号；跨季连续集号会核对前季分集总数，季内编号与连续编号都合法但结果不同时保留待确认，不按文件夹中的最小数字推算集号。纯数字默认第 1 季用于手动预填，不单凭这个默认值自动绑定。
- `11.5`、OVA/OAD 等特别篇按 TMDB 第 0 季查找；能通过标题对应，或第 0 季只有一个实际条目时填写真实集号，多条无法区分时需手动确认。MV/PV、NCOP/NCED、菜单和 Bonus 等附属视频跳过正片自动匹配及待匹配筛选，仍可在源目录和普通影视库中查看。
- 手动匹配页显示上次未确认原因和推荐候选，可点击中文目录名、文件原名等标题重新搜索。更新规则后直接刷新影视库即可重新处理已有待匹配文件，无需删除或重加媒体源；已确认 TMDB 身份及人工修正受到保护。
- 一次手动匹配指定一个作品；同一集的多个画质文件归为不同版本，不同电影请分别匹配或使用自动匹配。已有人工修正继续受锁定保护。
- 匹配到同一部作品的不同文件会合并到同一详情页。

### 本地纠错与锁定

- 不填密钥也能在详情页通过「本地编辑」修改标题、年份、简介和海报路径（TMDB 海报相对路径，如 `/abc.jpg`，留空清除）。
- 手动匹配或编辑后该作品会被锁定，之后的扫描与自动匹配不会覆盖你的修改；需要更正时再次编辑或匹配即可。

### 海报与缓存

- 海报来自 TMDB 并缓存到磁盘，缓存按策略自动回收，可进入「设置 → 海报缓存」页面清空。
- 搜索结果缓存 7 天、详情缓存 14 天；离线或无密钥时可继续使用已缓存内容和已保存的作品信息。

## 观看进度与首页

- 播放中约每 10 秒自动保存一次进度；暂停、定位、退出、切后台时也会保存。
- 再次打开未看完的影片会自动续播；不足 5 秒或已看超过 90% 的记录从头播放。同一部作品换文件版本时进度通用。
- 首页「继续观看」按最近观看排序（最多 20 部），同一部剧显示最近没看完的一集，优先使用上次的文件版本，文件不可用时尝试同一作品的其他版本。
- 首页「最近添加」按入库时间展示新作品。
- 播放出错时显示安全提示，可重试或换文件；突然断电、系统强杀等极端情况可能丢失尚未保存的进度。

在播放器里直接选择未入库的文件播放，不会创建影视库条目和观看历史。

## 跨设备同步

多台设备可通过同一个 WebDAV 目录手动同步观看进度和手动修正。同步默认关闭，只在你点击时执行，无需额外部署 Reelva 专用服务端。

### 配置与使用

1. 在「设置 → 跨设备同步」填写一个已有的 WebDAV 目录及可选用户名、密码；多台设备填同一个目录。Reelva 会在其中创建独立的 `reelva-sync-v1` 子目录。
2. 保存配置后，在每台设备上点「立即同步」。没有后台自动同步。

### 同步内容与限制

- 同步：观看进度、已看状态，以及人工修正过的标题、年份、简介、海报路径。
- 跨设备关联依赖 TMDB 身份：没有匹配到 TMDB 的作品只在本机有效，不会按同名文件猜测对应关系。
- 不上传：视频文件、目录索引、WebDAV 账号密码、TMDB 凭据。
- 冲突自动合并：两端同时修改同一条记录时，按修改时间与设备标识取唯一结果，不逐项确认；主动回退进度、从头重看也是有效修改。请保持设备系统时间准确。
- 本机还没有的影片记录会先保留为「待应用」，完成扫描与匹配后再次同步即可应用。
- 停用同步只删除本机同步配置，本地影视库与观看历史保留，远端已上传的记录也保留。
- **隐私提醒**：WebDAV 服务器的管理员可以读取同步目录中的观看记录，同步数据没有额外的端到端加密，请选择可信的服务器。

同步目前不包含收藏，也不提供账号系统；远端批次文件不会自动清理，长期使用后同步目录的文件列表会变长。

## 数据与隐私

- 扫描只建立索引，绝不复制、移动或上传原始视频。
- 数据库位置：Windows 在用户文档目录（`Documents/reelva.sqlite`），Android 在应用内部存储。移除媒体源不会删除观看历史。
- 日志会对密码、令牌、Cookie 等常见凭据和网络 URL 脱敏。
