# Reelva 用户指南

Reelva 是一款 Windows / Android 影视库播放器，用来管理并播放**你自己的视频文件**。它不提供任何视频资源：扫描只建立索引，不会复制、移动或上传你的视频。

安装步骤见[根 README](../../README.md)。本文按功能介绍日常使用。

## 快速上手

1. 打开应用，进入「媒体源」→「添加媒体源」，选择本地目录、WebDAV 或 SMB，再在配置页填写信息并添加。
2. 保存后即可返回并继续使用，在「媒体源」查看后台扫描状态，扫描完成后进入「影视库」点击刷新，匹配已有索引中的作品。
3. 点击作品进入详情，选择文件版本或剧集开始播放。
4. （可选）进入「设置 → TMDB 识别」配置页，填入 TMDB API 密钥，自动补全海报与简介。
5. 没看完的影片会出现在首页「继续观看」，点击即可续播。

只想临时播放一个视频？在首页点「打开播放器」，在播放页通过「选择本地视频」选择文件，或「输入网络链接」播放。这种方式不会创建影视库条目，也不会产生观看历史。

## 应用更新

在「设置 → 关于 Reelva」查看实际安装版本、手动检查更新，或点击「GitHub」进入项目仓库。自动检查更新默认开启，在启动后异步检查，24 小时内最多自动检查一次；关闭后仍可手动检查。自动检查失败时不打断使用，发现新版本会展示更新内容，播放期间延后至退出播放器再提示。

- Android：点击「下载并安装」下载适合本机架构的 APK，可查看进度、取消或重试。完成后打开系统安装器；首次使用时按系统提示允许 Reelva 安装未知应用，授权返回后继续安装，最终安装由系统确认。后续更新须保持正式签名一致。
- Windows：选择安装包或便携压缩包，由浏览器下载后自行安装或解压。
- 弹窗的「在 GitHub 查看此版本」打开正在展示的新版本页面。当前没有更新时，手动检查统一提示「暂无新版本」；网络失败提示检查失败。
- 正式版检查正式发布，Beta 版同时检查后续 Beta 与正式发布。更新设置只保存在本机。

## 媒体源

「媒体源」页面管理视频来源，所有来源共用同一套扫描、文件名识别与播放流程。

### 添加来源

点击「添加媒体源」进入来源选择页，再点击对应的来源卡片进入配置页。显示名称可不填；视频扩展名、排除目录和部分连接设置位于「高级选项」。常见填法：

| 类型 | 地址示例 | 其他填写项 |
| --- | --- | --- |
| 本地目录 | 点击「选择目录并添加」，通过 Windows 系统目录选择器或 Android 文件授权（SAF）选择文件夹；取消选择会留在配置页 | — |
| WebDAV | `https://nas.example/dav/Movies/` | 用户名、密码按需填写 |
| SMB | `smb://nas.example/Movies`（可带端口与子目录） | 账号、密码、域；支持匿名 |

注意事项：

- 根目录地址不要内嵌账号密码、查询参数或相对跳转段，凭据请填在对应输入框。
- 使用 HTTPS 的 WebDAV 需服务端持有可信 TLS 证书。
- SMB 仅支持 SMB2/3（含 NTLM 认证），不支持 SMB1。

### 扫描与源管理

点击媒体源卡片可进入文件目录，点击文件夹逐级浏览。文件与文件夹右侧的复选框用于选择视频，勾选文件夹会包含下级目录中的视频；支持跨目录选择，父文件夹会显示部分选中状态。「全选/清空」只切换当前打开目录范围内的选择，其他目录的勾选保留；未全选时补齐全选，已全选时清空。底部显示已选视频数量，可直接「自动匹配」或「手动匹配」。视频文件显示「未匹配」或已匹配的作品名、年份及季集信息，匹配完成后自动更新。

- 媒体源保存后立即返回列表并开始首次扫描，源卡片上实时显示已访问目录数与发现视频数，可随时取消；扫描失败会保留媒体源配置，可检查连接或权限后重新扫描。
- 扫描读取已有 NFO，但不会自动进行 TMDB 匹配。需要整理作品时，在影视库点击右上角刷新按钮，匹配已有索引中的待处理作品；需要重新读取目录或 NFO 时，使用媒体源卡片上的扫描按钮；应用启动和页面切换均不会触发匹配。源目录中的「自动匹配」仍可处理选中的视频。
- 空闲时可对单个来源重新扫描；扫描失败或取消不会清空已建立的影视库。
- 卡片菜单支持重命名、同根目录重新授权（Android 授权过期时使用）与移除来源。
- 移除来源只是停用它：作品、手动修正和观看历史都会保留，保存的密码等凭据会被删除；之后可重新添加同一来源。

### 视频筛选

默认只索引 `mkv, mp4, avi, mov, m4v, ts, webm` 扩展名的文件，并跳过 `.cache`、`$RECYCLE.BIN`、`System Volume Information` 等目录，添加来源时均可修改。

### 凭据安全

密码、令牌和播放请求头保存在系统安全存储，数据库不保存明文；输入框不回显旧秘密，源卡片菜单可「修改凭据」。

## 影视库与播放

- 影视库仅展示已匹配或人工确认的作品，一部作品只显示一张卡片，可向下翻页加载更多；搜索、分类和最近添加排序均限定在这些作品中。尚未匹配或未自动匹配成功的条目集中在「待匹配」页，确认后自动移入影视库。
- 电影详情列出各个文件版本；剧集详情通过横向季标签切季，左右滑动剧集卡片选集，选集区位于剧情简介前。单集只有一个版本时点击直接播放，多个版本时可选择文件；库中集数按不同季集统计，同一集的多个版本只计一集。
- 来源离线或文件缺失时记录仍保留，会提示错误，可重试或换文件。

### 播放器

Windows 底部居中显示「上一集、播放 / 暂停、下一集」，移动端显示「上一集、快退 10 秒、播放 / 暂停、快进 10 秒、下一集」。右下角的播放列表仅显示图标，与字幕、音量图标保持相同大小，点击可选集；剧集按季集排序，同集多个版本只显示一个，保留当前选择的版本，列表与左上角标题使用刮削后的集名。Windows 全屏按钮位于播放列表左侧，移动端隐藏全屏与音量按钮。还支持进度拖动、倍速、音量、静音，以及字幕与音轨选择（自动、指定轨道或关闭）。Windows 音量面板中的静音图标与滑块同行，取消静音时恢复之前的音量。本地目录、WebDAV、SMB 和 Android 授权目录均支持自动加载同目录匹配字幕，可在播放器设置中关闭或改为严格同名；模糊匹配还接受视频同名后带语言等后缀的字幕。Windows 本地文件另支持同目录音频自动加载。

在播放页的字幕图标菜单中，点击「选择本地字幕」打开系统文件选择器，或点击「选择媒体源字幕」浏览已添加的源和子目录，选中字幕后立即加载。音轨也通过图标菜单选择，已选项与悬停项统一使用圆角高亮。支持 SRT、ASS、SSA、VTT、SMI/SAMI 和 SUP，可切换已加载的字幕或关闭字幕。单独打开的 HTTP/HTTPS 视频地址、Android 单文件授权无法枚举同目录，也可使用这两个入口手动添加字幕。

点击视频后直接进入播放画面，返回、标题和播放控件悬浮在视频上方。播放时控件会自动隐藏，触屏点按可显示或隐藏，双击可播放 / 暂停；移动端在画面左半侧上下滑动调节亮度，右半侧上下滑动调节播放器音量，中间浮窗显示当前数值。亮度只影响当前应用窗口，退出播放器后恢复原设置；音量遵循播放器设置的上限。移动鼠标也可唤出控件，鼠标默认左键单击播放 / 暂停、双击切换全屏、右键打开播放菜单。Windows 音量面板展开期间控件保持可见，再次点击音量按钮、点击面板外部或按 Esc 可关闭。窄屏下，字幕、音轨和倍速收在「播放设置」中。

长按视频画面或按住右方向键约半秒，可临时以 3 倍速播放，上方中央显示「3倍速中」，松开后提示消失并恢复长按前的倍速。右方向键短按仍按原绑定快进，长按期间不连续跳转；切到后台或播放器失去焦点也会恢复原倍速。

右上角菜单中的「视频信息」与 Tab 打开同一个实时信息面板，显示视频、音频、解码与缓存统计。Windows 开始播放后按视频显示比例调整窗口客户区大小，避免窗口比例不符造成额外黑边；Android 横屏视频自动横屏播放，竖屏视频保持竖屏，退出播放器后恢复系统方向设置。返回时保留进入播放器前的页面与浏览状态。

快捷键仅在播放页生效，输入框和弹窗保留原有操作。按住定位、音量等连续调节键可重复操作，播放 / 暂停等切换操作不连发。逐帧和章节可用性取决于媒体本身，反向逐帧可能较慢。

「快捷键」采用左侧功能、右侧按键与操作按钮的紧凑行式布局。点击按键可修改，未绑定时点击＋设置，×可清除绑定；长组合键可悬停查看完整内容。页面可调整普通和大幅定位 / 音量步长，分别开关鼠标单击、双击、右键菜单和滚轮。纵向滚轮默认每次调节 2% 音量；横向滚轮向左前进 2 秒、向右后退 2 秒。重新绑定时按下目标按键或组合键，出现冲突时需更换按键或先清除原绑定；保存后下次进入播放器生效。「恢复默认值」只重置快捷键表单，仍需保存，不改动画质、缓存和字幕偏好。

### 播放器设置

进入「设置 → 播放器」调整以下选项，点击「保存设置」后，下次进入播放器生效。配置先保存在本机，配置同步按平台合并，快捷键可跨平台同步；「恢复默认值」会重置表单，仍需保存。

- **视频**：自动硬件解码、高质量缩放、去色带与抖动目标色深。Windows 默认开启高质量缩放和去色带；Android 默认关闭这两项以减少负载。色深默认自动，不强制假定屏幕支持 10 位输出。
- **缓存**：默认使用内存预读，不写入磁盘；Windows 前向缓存上限为 1024 MiB，Android 为 128 MiB，按需使用且不预先分配；另保留最多 64 MiB 的回退缓存。
- **音频**：倍速音调修正默认开启，最大音量默认 200%，可降至 100% 或 150%。100% 以上为软件放大，可能失真；同目录音频默认模糊匹配。
- **字幕**：默认优先中文、其次英文；可调整同目录加载规则、字体、字号、黑色描边、柔化、垂直边距、ASS 样式覆盖和随视频处理。字幕使用 libmpv/libass 渲染；Windows 默认微软雅黑，Android 附带 Noto Sans CJK SC 中文字体。普通文本字幕使用自定义字号和描边；覆盖 ASS 原有字体等样式时，需选择「使用自定义字幕样式」。

独立 mpv 的窗口、D3D11 后端、ICC 自动配置、显示同步插帧、SVP、截图与个人路径不直接套用到应用。具体适配说明见[播放器配置](../development/player_configuration.md)。

### 网络源播放

播放 WebDAV 文件时按需读取，随机定位取决于服务器是否支持 HTTP Range 请求；仅支持整体下载的服务器只能顺序播放。播放 SMB 文件时同样按需读取，无需预先复制整部视频。地址过期或访问被拒时会自动重新解析并重试，仍失败时给出提示，可手动重试或换文件。

## TMDB 识别与纠错

TMDB 配置是**可选**的：没有密钥也能浏览、播放和保存进度，只是无法获取新的在线资料，已保存和已缓存的内容仍可用。

### 配置密钥

在 [TMDB 官网](https://www.themoviedb.org/settings/api)申请后，于「设置 → TMDB 识别」配置页填入 API Key 或 API Read Access Token（可直接粘贴带 `Bearer` 前缀的令牌）。凭据保存在系统安全存储，可随时移除。

### 自动与手动匹配

- 点击影视库刷新按钮或源目录的「自动匹配」后，应用结合具体作品目录的中文标题与文件内原名、罗马音检索 TMDB；缺少年份也会搜索，带年份无合适结果时会移除年份过滤重试，再核验详情、别名、类型和季集。目录的字母索引、评分及画质标签不参与标题匹配，剧场版与 TV 分开识别；候选不确定时保留本地条目和推荐结果。
- 自动匹配最多同时处理 4 项，进度显示已处理数量及当前处理中数量。同一剧集共享搜索与季集结果，网络请求保留全局节流；遇到限流统一等待冷却，凭据无效时停止后续匹配。
- 整理结果中的「未自动匹配」是本轮尚未确认 TMDB 身份的本地条目数量，可能包含尚未归并的分集文件，不代表相同数量的独立作品。点击「查看待匹配条目」或影视库的「待匹配」筛选可查看当前列表，点击条目即可手动匹配，确认后会自动移出列表；同一剧集的多个文件也可在媒体源按文件夹批量匹配。
- 媒体源文件目录或作品详情页可打开统一的「手动匹配」页面：输入关键词与可选年份，一次搜索同时返回电影和剧集，无需切换作品类型。选择目标后预览文件对应关系，确认前不会修改匹配。确认成功后立即返回，NFO 与图片在后台保存；保存状态与失败重试入口显示在媒体源文件页、作品详情页和影视库，写回失败不会撤销已确认的匹配。
- 剧集优先读取文件名中的 `S02E03`、`1x05` 等季集号；单独的 `E03`、`EP03` 或纯数字集号可从所属 `S02`、`Season 02` 等文件夹补充季号。文件名为 `01`、`02` 等纯数字且没有季号时，默认填写第 1 季及对应集数；明确的文件或目录季号优先保留。其他缺失季号可批量补全，季集也可逐行修正或取消勾选。TMDB 确认季集存在后才应用；多集合集文件需取消勾选后单独处理。
- 支持字幕组常见的 `[01]`、`[13v2]`、`- 01` 编号；跨季连续集号会核对前季分集总数，季内编号与连续编号都合法但结果不同时保留待确认，不按文件夹中的最小数字推算集号。纯数字默认第 1 季用于手动预填，不单凭这个默认值自动绑定。
- `11.5`、OVA/OAD 等特别篇按 TMDB 第 0 季查找；能通过标题对应，或第 0 季只有一个实际条目时填写真实集号，多条无法区分时需手动确认。MV/PV、NCOP/NCED、菜单和 Bonus 等附属视频跳过正片自动匹配及待匹配筛选，仍可在媒体源目录中查看。
- 手动匹配页显示上次未确认原因和推荐候选，可点击中文目录名、文件原名等标题重新搜索。更新规则后直接刷新影视库即可重新处理已有待匹配文件，无需删除或重加媒体源；已确认 TMDB 身份及人工修正受到保护。
- 一次手动匹配指定一个作品；同一集的多个画质文件归为不同版本，不同电影请分别匹配或使用自动匹配。已有人工修正继续受锁定保护。
- 匹配到同一部作品的不同文件会合并到同一详情页。

### 本地纠错与锁定

- 不填密钥也能在详情页通过「本地编辑」修改标题、年份、简介和海报路径（TMDB 海报相对路径，如 `/abc.jpg`，留空清除）。
- 手动匹配或编辑后该作品会被锁定，之后的扫描与自动匹配不会覆盖你的修改；需要更正时再次编辑或匹配即可。

### 海报与缓存

- 海报来自 TMDB 并缓存到磁盘，缓存按策略自动回收，可进入「设置 → 海报缓存」页面清空。
- 搜索结果缓存 7 天、详情缓存 14 天；离线或无密钥时可继续使用已缓存内容和已保存的作品信息。

## 观看进度与首页

- 播放中约每 10 秒自动保存一次进度；暂停、定位、退出、切后台时也会保存。
- 再次打开未看完的影片会自动续播；不足 5 秒或已看超过 90% 的记录从头播放。同一部作品换文件版本时进度通用。
- 首页「继续观看」按最近观看排序（最多 20 部），同一部剧显示最近没看完的一集，优先使用上次的文件版本，文件不可用时尝试同一作品的其他版本。
- 点击「继续观看」的「查看全部」可进入观看历史页，按最近观看时间查看电影与各集的记录，包含已看完的内容，并可继续播放或打开离线作品详情。
- 首页「最近添加」按入库时间展示新作品。
- 播放出错时显示安全提示，可重试或换文件；突然断电、系统强杀等极端情况可能丢失尚未保存的进度。

在播放器里直接选择未入库的文件播放，不会创建影视库条目和观看历史。

## 跨设备同步

多台设备可通过同一个 WebDAV 目录手动同步观看进度，同步应用设置、媒体源、凭据与影视库索引，密码加密可选。索引快照携带已有作品资料和文件关联，新设备恢复后可以直接使用；媒体目录中的 NFO 继续保存影视资料。同步默认关闭，只在你点击时执行，无需额外部署 Reelva 专用服务端。

### 配置与使用

1. 在「设置 → 跨设备同步」填写一个已有的 WebDAV 目录及可选用户名、密码；多台设备填同一个目录。Reelva 会在其中创建独立的 `reelva-sync-v1` 子目录。
2. 配置、凭据和索引始终参与同步，无需设置密码；不设置时这些内容以普通 JSON 明文保存。如需加密，可填写独立的「同步加密密码」（至少 12 个字符），各设备必须相同；输入框不会回显密码，同一端点与用户名下留空会保留已有密码。加密密码遗失后无法读取原配置文件，更换密码需改用新的同步目录；启用加密不会自动删除已有的明文快照，需要避免保留明文历史时也应使用新的同步目录。
3. 保存配置后，在每台设备上点「立即同步」。没有后台自动同步，也不会因同步而扫描媒体源。

### 同步内容与限制

- 观看进度、时长与已看状态沿用增量批次同步；旧批次中的影视元数据修正不再应用。
- 配置文件包含媒体源名称、地址、启用状态、扫描扩展名与排除目录、网络账号密码及播放请求头、TMDB 密钥、播放器设置和自定义快捷键。播放器设置按平台分别合并，快捷键跨平台合并。
- 本地目录配置下载后显示「绑定本机目录」，需要重新选择对应目录并取得系统授权；另一台设备的路径不会直接启用。绑定后，各设备保留自己的路径。网络媒体源同步后直接恢复本机索引；本地目录绑定后直接套用已有索引，不触发首次扫描。Android 仍需系统目录授权；旧索引若只有不透明文档标识，需要选择原目录，或手动扫描一次建立可迁移路径。
- 跨设备关联依赖 TMDB 身份：没有匹配到 TMDB 的作品只在本机有效，不会按同名文件猜测对应关系。
- 索引快照同步目录与文件记录、可用状态、作品与季集资料、TMDB 身份、版本关联及目录图片的相对定位符；恢复时重新分配本机数据库编号，保留本机较新的作品修改。快照只读取本机 SQLite 数据，不会列出媒体源目录或读取全部 NFO。
- 不上传视频、字幕、目录图片或图片缓存；不复制设备标识、同步游标或 Android 目录授权。同步服务器连接信息仍需在新设备首次填写。
- 冲突自动合并：两端同时修改同一条记录时，按修改时间与设备标识取唯一结果，不逐项确认；主动回退进度、从头重看也是有效修改。请保持设备系统时间准确。
- 本机还没有的影片记录会先保留为「待应用」，完成扫描与匹配后再次同步即可应用。
- 停用同步只删除本机同步配置，本地影视库与观看历史保留，远端已上传的记录也保留。
- 加密为可选项：设置密码后使用 AES-256-GCM 加密配置与索引；未设置时使用普通 JSON。已有加密文件必须用原密码读取，缺少密码或密码错误不会覆盖远端。WebDAV 无需提供 ETag：原配置支持强 ETag 时条件更新，否则按设备分别保存配置快照，并在同步时合并并发修改。原有 `application-v1.json` 仍会读取，请保留整个 `reelva-sync-v1` 同步目录。观看进度的既有批次保持原格式，服务端管理员仍可读取观看记录。

同步目前不包含收藏，也不提供账号系统；远端批次文件不会自动清理，长期使用后同步目录的文件列表会变长。

## 数据与隐私

- 扫描只建立索引，绝不复制、移动或上传原始视频。
- 数据库位置：Windows 在用户文档目录（`Documents/reelva.sqlite`），Android 在应用内部存储。移除媒体源不会删除观看历史。
- 日志会对密码、令牌、Cookie 等常见凭据和网络 URL 脱敏。

## 随目录保存刮削信息

- 支持本地目录、Android 授权目录、WebDAV 和 SMB。自动匹配、手动匹配或修改元数据后，应用在视频目录保存 UTF-8 XML 格式的 NFO；原视频文件名和内容保持不变。
- 电影生成与视频同名的 `.nfo`，扫描单片目录时也读取 `movie.nfo`；电视剧在作品目录生成 `tvshow.nfo`，各集生成视频同名的 `.nfo`。已有 NFO 优先导入；已成功写回且之后没有本机修改的人工锁定条目，也能读取其他设备更新的 NFO。尚未成功写回的本机修改继续保留。旧版留下的人工锁定条目需先成功导出一次，建立写回记录。
- 海报与背景图保存为目录中的 `poster`、`fanart` 图片；同目录多部电影使用视频名作为图片前缀。目录图片通过媒体源读取，并沿用应用的图片缓存。
- 影视库右上角「导出已有影视库的 NFO 与图片」可导出现有刮削结果，不必重新匹配。已有第三方 NFO 中未编辑的演员、评分等字段会保留；损坏或指向其他作品的文件会报告错误，避免直接覆盖。
- 网络账号需要目录写入权限。旧 Android 目录授权只有读取权限时，先在媒体源重新授权目录；无法写入不影响已保存的匹配和观看历史，影视库会显示失败提示并提供重试。
- 图片下载失败时仍保存文字 NFO，图片可稍后重试。Kodi 等软件仍可能要求剧集视频文件名符合其季集命名规则。
