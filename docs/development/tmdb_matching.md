# TMDB 自动匹配规则与目录回归

## 处理链路

全库匹配只由影视库刷新按钮触发，刷新先扫描源并导入 NFO，再处理待匹配作品。启动、进入影视库及源扫描结束不触发 TMDB 检索；源目录仍可显式匹配所选视频。

初始扫描的本地识别与自动匹配均使用索引中的文件名和可信父目录。Local/WebDAV 使用源根内相对路径，SMB 使用共享内路径；SAF 仅解释可验证的系统外部存储文档层级，不透明文档标识降级为文件名。文件定位符与原媒体不被修改。

解析器保留具体作品目录名、文件原名及第二标题，过滤目录索引、末尾评分、发布组和技术标签；合集祖先不能覆盖具体子作品。季集、修订号、多集范围、特别篇和附属视频分别表示。无 TMDB 身份时，本地归组限定在相同源和作品目录范围，不能凭同名挂入已有人工锁或 TMDB 作品。

自动检索不再要求必须有年份。每个作品证据组合最多使用 3 个有来源的标题、6 次搜索和 3 次详情复核；电影、剧集按类型与 ID 去重。已知年份优先过滤，无精确结果时回退无年份检索；后续季的播出年份不直接用于过滤全剧首播年份。同一任务复用候选决策、搜索、详情与季请求，底层继续使用原有 TMDB 缓存、节流和 429 冷却。

全库刷新同时处理最多 4 部作品，源目录所选文件按作品检索证据分组后同时处理最多 4 组。单部作品的文件顺序核验；自动绑定和核对状态的数据库更新共用串行队列，实际变更仍在原有事务中执行。进度按已结束的工作累计，并显示当前处理中数量；中止时尚未派发的工作不计入已处理。

TMDB 客户端最多允许 4 个 HTTP 请求在途，只串行安排请求启动时刻，默认仍相隔至少 300ms。相同缓存键的并发调用共享同一个结果。429 在释放名额前更新所有请求共用的冷却截止时间，已经等待启动的请求也重新检查冷却；过长冷却及时报限流，不提前重试。401/403 阻止此前排队的同凭据请求，匹配任务停止派发后续工作；已在途任务结束后不再继续自动绑定，用户后续显式重试或更新凭据可以重新请求。

排名复用标题、原名、别名与年份评分，并对独立标题证据的精确命中加分。自动确认还需详情身份一致、可核验的标题或权威别名、类型及年份无冲突、相对第二候选有充分优势。短标题无年份且只有单一名称证据、目录简称与文件具体篇章冲突、只有模糊文字相似度时都保留推荐，不写 TMDB ID。

## 季集规则

- 文件明确季集优先；目录季号与文件冲突时不自动绑定。
- `[13v2]` 的 `v2` 是修订号。第 2 季以后的无季内标记编号会核对前季正片列表；前季编号需连续且完整，映射需落在实际季集内；绝对编号和季内编号都有合法但不同结果时留待确认。
- `[4th - 01][总第67]` 保留季内第 1 集与绝对第 67 集，不能互相覆盖。
- `01/02` 的第 1 季默认值用于人工预填。普通方括号编号缺少季号时，只有 TMDB 详情确认为单一正片季才允许使用第 1 季自动映射。
- 按用户补充，`11.5`、OVA/OAD 归第 0 季；通过特别篇标题或第 0 季唯一条目定位真实集号，不能把 `11.5` 舍入成 E11。明确 `S00E02` 仍须核验 E02 存在。
- 多集文件不绑定成单集；MV/PV、NCOP/NCED、Menu、Bonus 等不进入正片自动匹配或待匹配筛选，源文件仍可浏览、播放。

## 旧库与人工核对

全库刷新读取尚未绑定的作品及其原始文件索引，重新生成解析证据，已有 `needs_review` 无需重置为 pending 或重新扫描。解析阶段不批量拆并旧作品，确认 TMDB 身份和季集后才通过 `applyMetadataToFiles` 事务迁移所选文件及观看记录。人工锁、非本地元数据和已有 TMDB 外部身份均在应用前再次检查。

未确认原因与最多 3 个候选写入既有 `candidate_details`，保持 Schema v3；旧字符串格式仍可读取。手动匹配页展示推荐结果、原因和可切换的检索标题。网络、鉴权和限流错误单独报告，不计为“未找到候选”。

## 固定目录样例结果

样例从用户提供的 `cache/目录1.txt`、`cache/目录2.txt` 抽取，原文件名、父目录、来源行号和期望字段保存在 `test/fixtures/tmdb_directory_cases.json`。按这些增强规则标注的 21 条定向样例，修改前代码完整符合 2 条，修改后符合 21 条。这是标题、类型、季集与媒体分类的离线解析结果，不是全库统计或真实 TMDB 命中率。

| 目录样例 | 解析及核验行为 |
| --- | --- |
| `B_冰果/Hyouka [01]` | `冰果`、`Hyouka` 两路标题；无年份也检索，详情核实原名和实际季集 |
| `白箱（8.7）/白箱`、`白箱剧场版` | 去评分；TV 与独立电影分开 |
| `Fate/03 命运之夜前传（2011-2012）/Fate Zero [01]` | 使用具体子作品标题、原名与首播年，不使用泛化合集身份 |
| `物语系列/06. 囮物语/Otorimonogatari[01]` | 保留具体篇章查询，不凭系列前缀自动认领其他作品 |
| `Dandadan S02/[13]` | 前季 12 集且当前无 E13 时可映射 E01；两种编号均成立时待确认 |
| `Hyouka [11.5]`、`Another [OAD(00)]` | 第 0 季真实分集核验；不伪造集号 |
| `Re Zero [4th - 01][总第67]` | S04E01 与绝对编号 67 独立保留 |
| `怪奇物语/S05/4K HDR&DV/S05E01` | 穿透画质目录，保留具体作品与文件季集 |
| `ray MV`、`Other/Bonus/MenuJP1` | 附属视频，跳过正片绑定 |

模拟客户端集成测试中，一部 24 集的无年份剧集共使用 2 次搜索、1 次详情和1 次季请求；已匹配后再次刷新不再检索。负向用例覆盖短标题一字差、篇章冲突、年份/类型冲突、多集、编号歧义、人工锁和既有身份，不允许错误写入外部 ID。

未使用真实凭据验证在线召回、实际 TMDB ID、全库自动覆盖率及请求耗时分位数。没有执行应用构建或实机运行。
