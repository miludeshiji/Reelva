# 目录元数据与 NFO

作品元数据保存在 SQLite 索引中，可写媒体源同时通过 `NfoService` 保存到对应目录。`MediaSidecarAdapter` 在现有目录与播放接口之外提供有大小限制的小文件读取、目录文件写入及父目录定位；Windows 本地、SMB、WebDAV、Android SAF 共用此能力。百度、夸克、115、123 网盘使用 OpenList 的 `ReadOnlyMediaSidecarAdapter`：读取已有 NFO 与图片，复用账号授权和根目录边界，不上传或覆盖网盘文件。所有 I/O 在数据库事务之外执行，失败不回滚已确认的匹配或观看进度。

## 文件约定

- 电影：视频同名 `.nfo`，导入单片目录时兼容 `movie.nfo`。
- 电视剧：作品目录 `tvshow.nfo`，分集视频同名 `.nfo`；季集按数据库真实关联导出，保留原视频名。
- 图片：`poster`、`fanart` 加原图扩展名；同目录多部电影按视频名添加前缀，NFO 引用相对图片名。
- NFO 使用 UTF-8 XML 与 `movie`、`tvshow`、`episodedetails` 根节点，覆盖标题、原名、简介、年份、完整上映日期、TMDB 身份、季集及分集信息。分集使用自身真实 TMDB ID；旧数据没有提供商 ID 时使用独立的 `reelva` 本地身份，不能冒用整剧 ID。
- 不导出观看进度、凭据、临时播放地址或设备内数据库编号。更新同一条目的 NFO 时保留演员、评分等未知字段；损坏 XML 不会自动覆盖。

## 扫描与导出

扫描先建立视频索引，然后读取该目录 NFO，将电视剧上下文传入其子目录。NFO 不作为视频文件登记。导入保护尚未成功写回的本机修改；成功导出后在本机记录字段快照，人工锁定条目若与快照一致，可导入其他设备后续更新的 NFO，并保持锁定。旧版本的锁定条目需先成功导出一次；已确认 NFO 身份不再进入自动 TMDB 搜索。无外部身份的电视剧按实际目录上下文归组，不创建伪造 TMDB 绑定。多集、特别篇等缺少确切分集信息时保留待匹配状态。

自动和手动匹配、人工修改完成后向可写媒体源导出所涉及的文件；手动匹配在数据库提交成功后立即返回，所选文件的 NFO 与图片在后台写回，媒体源文件页、作品详情页和影视库显示保存状态及失败重试入口。自动导出跳过只读网盘，新匹配和人工编辑仍保存在本机 SQLite，并随影视库索引参与同步。影视库的导出按钮处理已有匹配结果，不向只读网盘上传。同一服务内的导出串行执行，避免同时写入同一剧的 `tvshow.nfo`。电视剧目录优先采用已有文件，其次跳过季与画质目录；源根含多个作品时不生成全库共用的电视剧 NFO。

## 权限与图片

本地和 SMB 使用临时文件写完后替换，WebDAV 对新文件使用条件 PUT，对已有 ETag 使用 If-Match。SAF 使用授权树中的真实文档 URI，通过原生接口读取和创建文件，重新授权时申请读写持久权限；旧只读授权需要用户重新选择目录。提供商拒绝写入时返回明确错误，不修改视频文件。

目录图片通过原媒体源授权读取，复用海报缓存，缓存键带条目的修改标记。网盘的小文件读取先解析直链和完整请求头，401/403 后单次重取，并沿用现有大小上限；不使用内核的无界文本读取作为 NFO 或图片接口。目录图片定位符放在独立字段，作品资料作为索引快照的一部分参与同步，以便新设备直接恢复；可写源中的 NFO 继续承担媒体目录的持久保存。TMDB 图片下载失败不阻止文字 NFO 保存，错误显示在影视库并可重试。

## 验证

```sh
fvm flutter test --no-pub test/features/metadata/nfo_service_test.dart test/features/sources/sidecar_adapter_test.dart test/core/database/nfo_migration_test.dart
```

真实 SMB、WebDAV 服务写入、Android 文档提供商的读写授权，以及四种网盘的既有 NFO / 图片读取仍需真实账号或设备验证。NFO 支持并不取代其他影视软件对视频名和目录命名的要求。
